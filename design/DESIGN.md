# WPF 深色凭据助手

## 已确定的方向

保留用户选择的 **02 深色仪表台**：石墨底色、浅蓝主操作、左侧抓包状态、右侧凭据结果。用户进一步确定采用 **C# + WPF**，以轻量、免安装、固定窗口为目标，完全移除浏览器内核。

设计目标：像现代 Windows 系统工具，下一步清楚，凭据易读，失败可直接复制或重试。

## 实现与范围

- 所有界面使用 WPF 控件及矢量绘图，按钮、输入框、复选框、下拉列表、滚动条均采用统一深色圆角样式。Microsoft Fluent 图标转为 WPF Geometry，中文优先使用 Microsoft YaHei UI，英文兼容 Segoe UI；Token 与设备 ID 使用 Consolas。
- Windows 管理标题栏、窗口边框、最小化与关闭；支持的系统使用深色标题栏和系统圆角。`ResizeMode=CanMinimize` 禁止用户拖拽缩放和最大化。
- 登录为 520×700、工作台为 1040×720 个逻辑像素，按系统 DPI 显示。登录表单预留错误提示空间，不使用滚动容器；较矮工作区自动收紧表单间距。主界面在工作区不足或内容较多时提供原生滚动，小工作区会将状态与结果上下排列。
- 界面与启动入口使用 C#，复用现有 Go 抓包内核，以匿名进程管道连接。内核压缩内嵌 EXE，启动后缓存于状态目录并以隐藏进程运行，不需要用户安装 Go。
- 移除 WebView2、网页资源、JavaScript 消息桥及对应依赖、许可证。没有界面 HTTP 服务，没有浏览器运行时依赖。
- 保留登录、证书安装与移除、开始与停止抓取、计数与状态、候选选择、完整 Token 与设备 ID 复制、自动提交、失败重试、换绑确认与取消、代理恢复和退出；保留编译时 `-DefaultServer` 地址预填。
- 凭据在提交失败、保存成功和取消换绑后保留在本次运行内；切换服务器重新登录时清除。管道断开取消当前请求并恢复代理，独立恢复守护进程继续保留。

未新增图表、抓包详情、历史记录等额外功能。运行目标为 Windows 10 1903 及以后、Windows 11 x64，使用系统自带 .NET Framework 4.8 或兼容版本。

## 视觉与交互

- 延续已确认的配色与信息层级，不重新探索方向。
- 左侧状态、计数、主操作、证书与说明使用固定区域，抓取前后保持尺寸与位置；计数从零开始显示，未捕获时隐藏右侧备用提示。
- 已获取时突出 Token 和复制；失败时将原因、保留提示与重试动作相邻放置；换绑时账号标签和值紧凑排列。
- 禁用主按钮退为灰色；状态图标保持小型圆角底板，避免抢占结果区。
- 保留按钮按下反馈、页面淡入、复制 Toast 和监听图标旋转。系统关闭界面动画时停止页面淡入与状态旋转。
- 实际渲染发现输入控件重复计算内边距，已从模板中移除重复内边距，并验证文字与密码区域能完整显示。

## 验证与证据

验证入口为 `../test.ps1`，使用模拟账号、虚构 Token、模拟面板和隔离状态目录。迁移初版连续验证结果：Go 内核三次均通过，WPF 第 1 次通过、第 2 次通过、第 3 次通过，Go vet 通过。另已验证自定义默认服务器和默认留空两种构建。实际验证包括：

- WPF 原生输入与按钮事件、编译默认服务器预填、密码显示切换及提交后清空、重新登录进入工作台。
- 输入文字和密码可见区域检查，防止仅验证值存在却忽略文字被裁剪。
- 候选切换、超过 24 KB 的 Token 原样显示与复制、设备 ID 复制及剪贴板失败提示。
- 提交失败后重试、确认失败后重试、成功后仍可复制、选择其他候选后可再次提交、取消换绑保留凭据。
- 关闭恢复失败时保留窗口并允许重试；内核连接故障时保留 Token，禁止新的后台操作。
- 固定窗口、受限工作区、无水平溢出、滚动后确认按钮可见。
- 实际内嵌内核的 UTF-8 中文登录、Cookie、编译地址一致性、关闭与管道断开后退出。
- Go 内核管道、凭据保留、会话/CSRF、重定向边界、HTTPS 抓包、代理恢复、Windows 证书私钥保护和目录锁回归，以及 Go vet。
